# Mi Librería

Página web sencilla para una librería, desarrollada como Proyecto Integrador del Curso de Git y GitHub.

## Qué hace

- Muestra una página de inicio con la bienvenida y el catálogo de libros.
- Permite agregar libros (título, autor y precio) y guardarlos en el navegador con localStorage.

## Tecnologías

HTML, CSS y JavaScript. No requiere instalación ni frameworks.

## Cómo ejecutarlo

1. Clona el repositorio:
   git clone https://github.com/Michell34/mi-libreria.git
2. Entra a la carpeta:
   cd mi-libreria
3. Abre el archivo index.html en tu navegador.

## Flujo de trabajo

- main: versión estable.
- develop: rama de integración.
- feature/nombre-tarea: ramas de cada funcionalidad, integradas a develop mediante Pull Request.
